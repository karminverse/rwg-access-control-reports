**ADDED outside the timelock, and this is the part worth holding:**

- At block 26,004,463 the Stake DAO multisig **granted itself** the locker-only setter on the new
  allocator and used it three times. It already held the same permission on the old allocator, so
  this restores a standing capability rather than creating a new kind, and it did not take the
  batch form of the same setter.
- At block 26,024,856, **five and a half hours before this window closed**, the same multisig moved
  a routing rule from the old strategy to the new on a guard contract outside the scanned set.
- Both are within its standing authority. Both skipped the 5-day delay. **The timelock buffered the
  pointer swaps but not the moves that completed the migration**, so the review window this asset's
  control model leans on is partial in practice.

**What did not happen, checked rather than assumed.** The migration function was not called and the
collateral did not move: the locker's gauge balance rose only by an ordinary user deposit, and the
non-locker balance is byte-identical at both endpoints. The locker-only restriction was dropped at

principal sits with the locker. The allocator swap also left routing untouched, with the withdraw
target set identical at both endpoints on the old and new allocator alike. The roster vault itself
recorded zero events and a byte-identical supply.

**What the new code cannot do**, read from verified source: the sidecar withdrawal sends only to
the protocol controller's registered vault, never to the caller or an arbitrary address; rebalancing
re-deposits only to allocator-returned targets. It cannot mint the SaveDola LP, scrvUSD, sDOLA or
DOLA: the new strategy's minter is Curve's canonical CRV minter, identical to the old one, so the
swap moves CRV emission claims and nothing else. None of it reaches the market's ceiling, its
oracle, its borrow pause or DOLA supply.

**Also cleared:** the queued shutdown call that the scanner rendered as targeting this vault's own
gauge in fact targeted an unrelated dormant legacy gauge. This vault's gauge reads not shut down at
both endpoints.
